AI Governance, hands on

Governance is a clear record of who decided, on what evidence, and who answers for it. These modules teach it by doing: each one builds something small, measures it, and writes down the evidence.

Module 1

Prompt Evaluation

How to tell whether a prompt is any good, and what actually improves it. Lessons for anyone who writes prompts, plus optional hands-on code with DSPy and a small AI model on your own computer.

Approach

How the modules work

💻Local first

The examples use open AI models that run on your own computer. No data leaves it, and each run costs nothing.

📏Measured, not claimed

Every result on these pages comes from a run you can repeat yourself. That includes the ones that did not work.

🤝People sign off

Code checks the things that can be counted. People make the judgement calls, decide what is fair, and answer for the result.
