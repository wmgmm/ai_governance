# AI Governance: learning resources

Hands-on modules for learning AI governance. Each builds something small, measures it, and
keeps the evidence.

Site: https://wmgmm.github.io/ai_governance/

| Module | What you learn |
|---|---|
| [`prompt_evaluation/`](prompt_evaluation/) | Measure and optimise a prompt with DSPy on a local Gemma model (llama.cpp), using AI governance exam questions as the example |

## Layout

- `<module>/`: code, data and results for each module
- `site/`: the GitHub Pages site (plain HTML, style from The Matts workshop site), published by `.github/workflows/pages.yml`
- `docs/`: reference material
